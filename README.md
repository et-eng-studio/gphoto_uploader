# Google Photos Helper

Google Photos can only import photo files in a 'flattened' folder.

If you have a folder with many sub folders (recursively), it is very tedious to import all the photos.

The script here can copy all files in the source folder to the target folder in a 'flattened' way.
* Files with same names won't overwrite each other.
* The copied files will keep the same timestamp as the original files.
